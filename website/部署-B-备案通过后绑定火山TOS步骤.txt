================================================
B. shaw.cn 备案通过后 — 5 分钟绑定到火山 TOS（正式上线）
================================================
等 shaw.cn 的 ICP 备案审核通过（收到短信：「京ICP备2026xxxxxx号 已通过」），
按下面 5 步做，绑定到火山 TOS 的 shaw-space-website Bucket，
实现全世界输 https://shaw.cn 直接看官网。

前提条件：
- shaw.cn 备案状态=通过（工信部有记录）
- 您已按之前发的火山 TOS 控制台 6 步创建好 shaw-space-website Bucket
  （公共读 + cn-beijing 区域）
- website/ 全部内容（index.html、css、js、images）已经上传到 Bucket 根目录
- 静态网站托管功能已开启（默认主页 index.html）

------------------------------------------------
步骤 1：下载「SSL 免费证书」（必须有，才能开 HTTPS 🔒）
------------------------------------------------
两种方法二选一，推荐用腾讯云/阿里云（和您买域名的平台同一个）：

方法一：腾讯云（如果域名在腾讯云买的）
  访问 https://console.cloud.tencent.com/ssl
  → 点「申请免费证书」→ 选 TrustAsia / 域名型 DV / 免费版（一年免费 20 张）
  → 域名填：shaw.cn
  → 额外域名勾选上：www.shaw.cn
  → 绑定邮箱（767271878@qq.com）
  → 验证方式：选「自动 DNS 验证」（最快，平台自动帮您加解析记录）
  → 提交申请，等 1～10 分钟审核通过 → 在「证书列表」里下载「Nginx 格式」的 .crt 和 .key 两个文件到本地。

方法二：火山引擎（直接在火山控制台买也可以）
  访问 https://console.volcengine.com/certificate/
  → 「购买证书」→ 选「免费证书 DV」→ 0 元 → 下单
  → 绑定 shaw.cn 和 www.shaw.cn → 提交审核
  → 通过后下载证书 PEM+私钥 KEY。

------------------------------------------------
步骤 2：火山 TOS 控制台 → 「绑定自定义域名」
------------------------------------------------
1. 打开 https://console.volcengine.com/tos
2. 进入桶列表 → 点您的 shaw-space-website 桶 → 进详情页
3. 左边侧边栏：找「**基础设置**」→ 展开点「**自定义域名**」（有的写"域名管理"）
4. 点蓝色「**添加自定义域名**」按钮 → 弹窗填：
   - 自定义域名：shaw.cn        （先加主域名）
   - 源站：选当前桶 shaw-space-website.tos-cn-beijing.volces.com
   - 协议：HTTPS（强制推荐，不要 HTTP）
   - SSL 证书：点「选择证书」→ 上传您刚才下载的 shaw.cn 的 .crt 和 .key
   - 开启「强制 HTTPS 跳转」（用户输 http:// 自动跳 https://，更安全）
   - 点「确定」→ 保存成功。
5. **再加一条**（同样操作点「添加自定义域名」）：
   - 自定义域名：www.shaw.cn
   - 源站：同一个桶
   - SSL 证书：上传 www.shaw.cn 的证书（同一张一般能兼容，看证书的 SAN 列表）
   - 同样开 HTTPS + 强制跳转。

保存好后，列表里会显示两条记录：
  shaw.cn      证书绑定成功 / CNAME 目标：xxxxxx.tos-cn-beijing.volces.com
  www.shaw.cn  证书绑定成功 / CNAME 目标：xxxxxx.tos-cn-beijing.volces.com

------------------------------------------------
步骤 3：去域名解析后台 → 加 2 条 CNAME 解析记录
------------------------------------------------
（在哪买的域名就去哪的控制台加解析，例子用腾讯云）

1. 打开：https://console.cloud.tencent.com/cns
   （如果是阿里云就开：https://dns.console.aliyun.com/）
2. 找到您刚买的 shaw.cn，点右侧「**解析**」按钮 → 进「记录管理」
3. 点蓝色「**添加记录**」按钮，分两次加：

① 第 1 条（主域名 shaw.cn）
  - 主机记录：@        （代表根域名 shaw.cn，不带 www）
  - 记录类型：CNAME    （下拉选 CNAME，不要选 A！因为我们是转到另一个域名）
  - 线路类型：默认
  - TTL：600 秒（默认）
  - 记录值：粘贴步骤 2 里火山给的 CNAME 目标值（形如 shaw-space-website.tos-cn-beijing.volces.com）
  → 点「确定」保存。

② 第 2 条（www.shaw.cn）
  - 主机记录：www
  - 记录类型：CNAME
  - 线路类型：默认
  - 记录值：粘贴步骤 2 里的同一条 CNAME 目标值（和 @ 一样）
  → 点「确定」保存。

------------------------------------------------
步骤 4：（可选但强烈推荐）开 CDN 加速，全球访问更快
------------------------------------------------
如果 TOS 直接访问速度不理想，再加一层 CDN（火山 CDN 也在同一控制台）：
1. 打开 https://console.volcengine.com/cdn
2. 「添加加速域名」→ 加速域名填 shaw.cn 和 www.shaw.cn
3. 源站选「对象存储 TOS」→ 选 shaw-space-website 桶
4. 证书选和 TOS 绑定的那张 SSL 证书
5. 最后会生成一个形如 cdn-shaw.cn.volc-cdn.com 的新 CNAME 值
6. 回到步骤 3 的解析后台，把 @ 和 www 的 CNAME 记录值从 TOS 那个改为 CDN 这个新值。

（备案下来再做这步，先做前 3 步就够用了）

------------------------------------------------
步骤 5：测试，正式生效！
------------------------------------------------
等 10 分钟（DNS 生效时间，全球有延迟），然后：

① 浏览器里输入：
  https://shaw.cn
  https://www.shaw.cn

都能看到 Shaw Space 官网、🔒 浏览器地址栏有安全锁、点 App 卡片能弹详情、
右侧 Agent 聊天框能打字 → 恭喜！正式上线成功🎉。

② 如果打不开或显示不安全：
- 先等 30 分钟（DNS 全球同步慢的情况）再试
- 检查证书是不是选对了，域名是不是完全匹配
- 检查 Bucket 桶策略是不是「公共读」（私有会 403 拒绝访问）
- 检查 index.html 是不是放在 Bucket 根目录（放在 css/ 这种子文件夹里会 404）

做完给我发一句：「shaw.cn 能打开了！」～ ✅
